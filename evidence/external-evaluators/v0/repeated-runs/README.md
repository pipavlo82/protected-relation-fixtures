# PRF external-evaluator repeated-run evidence v0

This additive lane preserves 180 new local, oracle-blind evaluator observations: ten independent invocations for each of six frozen PRF v0 challenges across three recorded Ollama model configurations. Raw bytes were captured before parsing and before benchmark-side scoring. Each scheduled observation had one attempt and no semantic retry.

Adapter execution status, semantic outcome, and benchmark mismatch classification remain separate. Adapter failures are not converted to `UNVERIFIABLE`. The historical first-run evidence is used only for recurrence comparison and is not part of the fresh n=10 denominator. Pre-wrapper-repair Qwen evidence is not a comparable semantic baseline.

The exact payload inventory binds imported experiment files. Derived JSON summaries and `REPORT.md` are independently recomputed by the validator from the committed observation evidence and frozen v0 authority.

These results characterize the recorded repeated blind observations under the frozen PRF v0 benchmark and recorded evaluator configurations. They do not establish universal model behavior, deterministic semantic outcomes, statistical significance by themselves, or external-domain truth beyond the benchmark authority.
